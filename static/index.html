        01 / 原片理解与多人对白校准

        可选上传 SRT 字幕。系统将整理镜头、台词、核心人物、人物关系、场景、剧情单元、情绪变化、产品出现时间和前三秒吸引力。

        原片镜头参考

        用于观察原片的景别变化、构图、人物站位、动作衔接、色调与产品露出；不是更换人物和场景后的二创九宫格。

        02 / 准备人物、产品与场景资产

        可为同一人物上传不同剧情阶段的造型图，也可加入产品图和新场景参考图；不参与本轮的素材可以隐藏。

        03 / 新短剧脚本

        保留原片的时间结构与镜头逻辑，人物、产品和台词按本次素材重新创作。表格内容可直接修改。

        04 / 连续分镜组与九宫格方案

        按剧情节奏自动拆分分镜组，并整理景别变化、人物、服装、场景、产品引用和九宫格画面规划。

        05 / 视频提示词包

        系统会按分镜顺序将连续镜头组合成所选时长，供后续视频生成工具继续使用。
