# VideoInsight · 视频解析工具

支持任意平台视频的**关键信息提取、总体总结和 Remix 衍生创作**的网页工具。粘贴一段视频链接（或 App 分享文案），自动下载解析，逐条提取关键信息（按重要性排序），最后生成一段总体总结；教育类视频还会输出教学观点与讲解思路，并生成观点卡片、60 秒口播脚本、金句摘录等二次创作素材。

## 功能

- **通用链接解析**：粘贴**任意平台**的视频链接或整段 App 分享文案——B 站 / 微博 / 西瓜 / YouTube 等 1000+ 站点（yt-dlp 引擎）、抖音 / 小红书（自研移动端分享页解析器）、视频直链，系统自动提取链接并多级降级解析
- **三小时本地视频**：mp4 / mov / webm 等，浏览器本地均匀抽取最多 36 张关键帧，原视频不上传
- **内容理解**：ffmpeg 均匀抽取关键帧（自动去重），交给多模态大模型（阿里百炼 Qwen-VL 系列）理解画面内容
- **语音联合分析**：可读取的在线视频链接会调用阿里百炼长音频转写，并将语音内容与关键帧联合分析；平台阻止音轨读取时自动降级为仅画面分析
- **关键信息提取（核心）**：8-12 条关键信息，按重要性排序，覆盖主题、人物、事件、数据、方法、结论，没看过视频也能读完掌握全部要点
- **总体总结**：150-250 字综合总结全片（讲了什么 / 结构 / 核心结论 / 适合谁），作为报告收尾
- **章节时间轴**：按关键帧顺序估算时间点划分章节
- **教学观点提炼**：针对教育类视频输出教学主张、讲解思路、适合人群
- **Remix 衍生创作**：观点卡片、60 秒短视频口播脚本、金句摘录，支持一键导出 Markdown 报告
- **受控 Agent 创作台**：千问先根据视频类型和用户目标规划路线，再从白名单工具中动态选择“多平台二创包”或“课程整理包”；最多两步，并对输出做结构质检，避免无限循环和不可控费用
- **双场景入口**：解析前明确选择“课程与讲座复盘”或“内容整理与二次创作”，基础分析完成后自动生成对应成果，不需要在报告底部再次选择
- **多平台二创包**：15/30/60/90 秒脚本、精彩片段建议、分镜、小红书文案与短视频口播稿
- **课程整理包**：学习目标、课程大纲、PPT 页面内容、逐页讲师备注和练习题；支持继续编辑并随报告导出
- **原生文件导出**：服务端生成真正的 `.pptx` 与 `.pdf` 文件，和 Markdown、Word 一起直接进入浏览器下载队列
- **最近任务**：自动在当前浏览器中保存最近 10 份报告，可随时恢复；记录不会上传，也不会与其他访客共享
- **失败恢复**：区分平台限制、登录权限、服务繁忙、额度和网络问题，并支持一键重新尝试
- **报告编辑与导出**：结果可直接修改，并可导出 Markdown、Word 或通过打印窗口保存为 PDF
- **章节定位**：本地视频和可直接播放的视频链接支持点击章节时间跳转到对应画面
- **演示模式**：无需 API Key 即可体验完整流程

## 架构

```
浏览器（中文单页应用）
   │  上传视频 / 粘贴任意平台链接
   ▼
FastAPI 后端（本机运行）
   │  1. 链接解析：抖音/小红书自研解析器 → yt-dlp 通用引擎 → 直链下载（多级降级）
   │  2. ffmpeg 抽关键帧（imageio-ffmpeg 自带，无需单独安装，静态画面去重）
   │  3. 可读取链接调用百炼 ASR 转写语音（失败自动降级）
   │  4. 帧序列 + 语音转写 + 结构化提示词
   ▼
阿里百炼 Qwen-VL（OpenAI 兼容接口）
   │  返回严格 JSON（失败自动重试）
   ▼
前端渲染：分析报告 + Remix 素材 + Markdown 导出
```

Agent 深度创作采用独立的受控链路：

```
已有视频报告 → Qwen 文本规划器 → 白名单工具选择（最多 2 个）
             → 二创包 / 课程包生成 → 结构完整性质检 → 编辑与导出
```

这里的 Agent 不是开放式无限自治：模型负责选路线，后端负责权限、步骤上限、输入裁剪、失败重试和结果校验。默认文本规划模型可通过 `VI_AGENT_MODEL` 配置，默认为 `qwen-plus`。

实现思路参考了开源社区的可组合工作流设计，包括 Vidify 的分层编排、NovaClip 的 Director/Editor/Reviewer 思路、Kinocut 的受控工具与质量门，以及 analysis-video 的课程视频结构化方法。本项目当前只借鉴架构思想，没有复制这些仓库代码或引入其运行时，因此不会把 AGPL 等不同许可证代码混入当前项目。

设计取舍：本地文件的原视频留在用户浏览器中，后端只接收压缩关键帧，因此本地大文件默认仅做画面分析；可读取的在线视频链接会尝试语音转写。链接解析下载的临时视频会在请求结束时删除。公网部署默认隐藏本地配置入口，并禁止访客通过 `/api/config` 提交 API Key 或登录 Cookie。

## 本地运行

```bash
pip install -r requirements.txt
python make_sample.py      # 可选：生成示例教学视频 sample_lesson.mp4
uvicorn app:app --port 8765
```

打开 `http://127.0.0.1:8765`，点右上角「设置」填入阿里百炼 API Key（[获取教程](https://help.aliyun.com/zh/model-studio/get-api-key)），或先点「演示模式」。

## 公网部署（分享给招聘者 / HR 的安全模式）

本地自用时 Key 存在 `config.json`（已被 `.gitignore` 排除）。公开分享时使用**部署模式**，通过环境变量注入，确保 API Key 无法被访问者获取或滥用：

```bash
VI_API_KEY="sk-你的密钥" \
VI_ACCESS_CODE="自定义访问码" \
VI_DAILY_LIMIT="20" \
uvicorn app:app --host 0.0.0.0 --port 8765
```

部署模式下的隐私保障（已逐项验证）：

| 措施 | 效果 |
|---|---|
| Key 仅存于服务端环境变量 | 前端页面无设置入口，`/api/status` 只回传布尔值，永不暴露明文 |
| 访问码校验 | 所有解析接口需携带正确访问码（`hmac.compare_digest` 防时序攻击），只把「链接 + 访问码」发给对方 |
| 配置接口禁用 | `/api/config` 在部署模式下返回 403，访问者无法替换/窃取 Key |
| 每日用量限额 | `VI_DAILY_LIMIT`（默认 20 次/天）限制每日真实解析次数，访问码外泄也不会刷爆额度 |
| 错误信息脱敏 | 不向浏览器返回模型供应商的原始响应正文，也不把 Key、Cookie、请求体或用户链接写入日志 |
| 仓库防误提交 | `.gitignore` / `.dockerignore` 排除配置、环境变量、证书、Cookie 和 secrets 目录；CI 模板检查疑似 API Key |

如果密钥曾经真实提交到 Git、截图、聊天或公开日志中，仅从文件删除并不安全：应立即在百炼控制台撤销旧 Key、创建新 Key，并只把新 Key 填入 Render 的 Secret 环境变量 `VI_API_KEY`。

需要把源码发给别人时，不要直接压缩整个工作目录。运行 `powershell -ExecutionPolicy Bypass -File scripts/build-safe-release.ps1` 生成安全源码包；它只包含已提交文件，不会带入本地配置、Cookie、下载视频、日志或 Git 历史。

## 生产运行基线

- `/api/health` 是进程存活检查；`/api/ready` 同时检查 API Key、FFmpeg 和静态资源，未就绪返回 503。
- 仓库包含 `ci.workflow.example.yml` CI 模板，可执行 Python 语法检查、稳定性测试和 Docker 构建。启用前需用具备 GitHub `workflow` 权限的账号将其放到 `.github/workflows/ci.yml`。
- Docker 容器使用非 root 用户运行，依赖使用精确版本，构建上下文排除测试视频和临时诊断文件。
- 本地关键帧分析与链接解析使用独立并发池，避免单个长链接阻塞所有用户。

当前每日配额保存在单实例内存中，适合免费层和作品集流量。正式商业部署必须将配额、用户和任务状态迁移到 Redis/PostgreSQL，并使用独立任务队列；否则扩容到多个实例后无法保证全局一致限额。
